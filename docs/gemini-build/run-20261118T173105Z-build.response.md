### 4. Assumptions & Design Choices

1. **Anti-Windup Integration Guard:** Implemented per user clarification: $(K_c/\tau_I)\cdot S$ is retained in controller output whenever $\text{mode} \ne \text{'P'}$, including while frozen; freezing halts state accumulation ($S_{\text{trial}} = S_{k-1}$) without zeroing the integral term.
2. **Conditional Slider Visibility:** Controls specific to feedforward pre-boluses, setpoint deviations ($\beta$), or sensor faults are conditionally displayed when those options or presets are active, ensuring all visible sliders directly impact the simulation and pass automated smoke verification.
3. **Stability Margin Grid:** Computed using a 3,000-point logarithmic frequency search over $[10^{-5}, 10]\text{ rad/min}$ with high-precision bisection on zero-crossings for $\omega_c$ and $\omega_{180}$.
