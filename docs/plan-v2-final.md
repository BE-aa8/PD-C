## 5. Discrete PID (v1 §7, pinned)

Runs only at sample instants; output held between them (ZOH). At sample k: r_k set point, m_k measurement, e_k = r_k − m_k,
y_nom = G_basal.

```
P_k   = Kc · [ β·(r_k − y_nom) − (m_k − y_nom) ]                       [C 13]
d_k   = α·d_{k−1} + (1−α)·(m_k − m_{k−1})/Ts ,  α = τf/(τf + Ts), τf = τD/N   (α = 0 if τD = 0)
D_k   = −Kc·τD·d_k                                                       (derivative on measurement)
bumpless start: S_0 = 0, d_0 = 0, m_{−1} = m_0
integrate = (mode ≠ P) AND NOT frozen            # whether S may change this sample
S_trial = integrate ? S_{k−1} + e_k·Ts : S_{k−1}
u(S)  = U_basal + P_k + (mode ≠ P ? (Kc/τI)·S : 0) + D_k
        # the integral TERM stays in the output whenever mode ≠ P, including while frozen;
        # "frozen" only stops S from changing (clarified 2026-11-18 after Gemini's plan run)
```

Anti-windup (judged on the **feedback output alone**, never on feedback + bolus `[C 5]`):

- **clamp:** u_trial = u(S_trial). If integrate and [(u_trial > U_max and Kc·e_k > 0) or (u_trial < U_min and Kc·e_k < 0)],
  then S_k = S_{k−1}, else S_k = S_trial. u_k = u(S_k), U_fb = clip(u_k, U_min, U_max).
- **backcalc** `[C 2, 3]`: u_k = u(S_trial); U_fb = clip(u_k, U_min, U_max);
  S_k = S_trial + Ts·τI·(U_fb − u_k)/(Kc·Tt) if integrate, else S_k = S_trial.
  **Tt = max(√(τI·τD), Ts)** if τD > 0, else Tt = τI.
- **off:** S_k = S_trial; U_fb = clip(u(S_k), U_min, U_max).
- **NaN measurement (dropout):** hold the previous U_fb and leave every controller state unchanged.
- **Frozen** (optional "suspend integral during bolus"): see §7.

## 6. Sensor (v1 §8, pinned) `[C 17, 18]`

- Lag: if τs > 0, a 4th RK4 state dGl/dt = (G_abs − Gl)/τs, with Gl(0) = G_basal; if τs = 0, Gl = G_abs after every step.
  Allowed τs: 0 or 0.5–15 min.
- Delay: delay_steps = round(θs/dt). A ring buffer of Gl values, pushed once per dt step, pre-filled with G_basal; the reading
  at step i is the value pushed at step i − delay_steps.
- Noise (UI only; never compared across languages) `[C 8]`: Gaussian σ via **Mulberry32 + Box–Muller** seeded with `seed`;
  one draw per sample read. The same seed must give identical arrays.
- Faults: **stuck** (t ≥ t_fault returns the last good reading taken before t_fault); **drift** (adds
  drift_rate·(t − t_fault)/60 for t ≥ t_fault); **dropout** (NaN for t_fault ≤ t < t_fault + dropout_duration).

## 7. Meals and feedforward (v1 §9–§10, pinned) `[C 5]`

- D(t) = Σ_i A·mult_i·e^(−k(t − t_i)) for t ≥ t_i (A = 9.0, k = 0.05). **Presets use t_meal = 60 min**; the open-loop unit test
  uses t_meal = 0 `[C 14]`.
- **Bolus per meal** = f_bolus · Kf · (1 + est_error) · A · mult / k (textbook meal → 1390.09 mU). It starts at t_meal − t_pre.
- Per dt step (after the controller, before integration):
  1. Queue every bolus with start ≤ t + 1e-9 (remaining += its total); record the delivery start if the queue was empty.
  2. If remaining > 1e-9: cap = max(0, U_max − U_fb) where **U_fb is the clipped feedback output**;
     U_ff = min(cap, remaining/dt); remaining −= U_ff·dt. If remaining ≤ 1e-9 after this step: remaining = 0, record the delivery end
     t + dt, freeze_until = t + dt + suspend_extra.
- **Suspend-integral option:** at a sample instant, frozen = ff_enabled AND suspend_integral AND (remaining > 1e-9 OR
  t < freeze_until), evaluated **before** that step's bolus queue update.
- A bolus scheduled before t = 0 is delivered starting at t = 0, with a warning.
- Ideal Gf(s) is improper (v1 §10.1); show the derivation. Lead–lag FF (v1 §10.3) is **not** required.

## 8. Simulation engine (v1 §11, pinned) `[C 15, 16]`

Fixed-step classical RK4, dt = 0.1 min; grid t_i = i·dt, i = 0 … N, N = round(t_end/dt); steps_per_sample = round(Ts/dt).
Initial state G = X = I = 0, Gl = G_basal, U_fb = U_basal (or U_open_loop when controller = `none`), G_meas = G_basal.
For each i:

1. sp = the last setpoint_step value with t + 1e-9 ≥ t_step (else `setpoint`); p3 scale = factor if t + 1e-9 ≥ t_s (else 1).
2. If G + G_basal ≤ 0 → mark invalid and stop (warning).
3. Push Gl into the delay buffer.
4. If i % steps_per_sample == 0 (integer arithmetic): G_meas = sensor read; if controller = `pid`: U_fb = PID update (§5).
5. U_ff = feedforward step (§7); U = clip(U_fb + U_ff, U_min, U_max) (no clip when saturation = false).
6. D evaluated at **t, t + dt/2, t + dt** (RK4 stage times).
7. Log t, G_abs, G_meas, U, U_fb, U_ff, D, then one RK4 step (U and p3 scale held over the step) if i < N.

After the loop: if min G_abs < 40 mg/dL, add a warning that the model has no counter-regulation, so this part is
qualitative only (40 is a labelled display threshold, not from a source).

## 9. `model.js` API contract (graded by `npm test`)

All exports are pure functions. Units are as in §2.

```js
export const DEFAULT_INPUTS;            // §9.1, every key, exactly these defaults
export function linearModel();          // {U_basal, Kp, Kd, tauG, tauX, tauI, Kf, authorityRatio}
export function nonlinearGain(dU);      // G_ss/dU (analytic, §3)
export function halfRule();             // {sopdt:{K,tau1,tau2,theta}, fopdt:{K,tau,theta}}
export function imcTuning({model, tau_c, theta_sensor, Ts, include_zoh});   // {Kc, tauI, tauD, theta_total}
export function margins({Kc, tauI, tauD, N, theta});   // {wc, PM_deg, GM, dtheta_max, total_tolerable_delay}
export function simulate(inputs);       // merges inputs over DEFAULT_INPUTS; returns §9.2
export function metrics(result, band);  // band = {low, high}; returns §9.3
```

### 9.1 `DEFAULT_INPUTS`

```js
{ t_end: 660, dt: 0.1, Ts: 5,
  controller: 'pid', mode: 'PID', Kc: -0.4256…, tauI: 70.297…, tauD: 17.574…,   // = imcTuning(default), full precision
  N: 10, beta: 1, anti_windup: 'clamp', U_open_loop: null,
  setpoint: 81, setpoint_steps: [],                       // [[t, absolute set point], …]
  sensor_delay: 10, sensor_lag: 0, noise_sd: 0, seed: 0,
  fault: 'none', t_fault: 60, drift_rate: 0, dropout_duration: 30,
  meals: [[60, 1]],                                       // [[t_meal, multiplier], …]
  ff_enabled: false, f_bolus: 1, est_error: 0, t_pre: 0, suspend_integral: false, suspend_extra: 0,
  sensitivity_change: null,                               // null or [t_s, factor on p3]
  saturation: true }
```

### 9.2 `simulate()` result

`{ t, G, Gm, U, Ufb, Uff, D }` (arrays of length N + 1; G and Gm absolute mg/dL; Gm null/NaN on dropout),
`valid` (bool), `warnings` (array of strings), `bolusPlanned`, `bolusDelivered` (mU).

### 9.3 `metrics()` result (on true glucose)

`peak, t_peak, nadir, t_nadir, pct_in_band, pct_in_70_180, pct_below_54, pct_below_70, pct_above_high, pct_above_180,
IAE, insulin_total, insulin_ff, time_at_Umax, time_at_Umin, stayed_in_band`.
Definitions: time fractions = trapezoid rule on the 0/1 indicator ÷ horizon (band strict: low < G < high; 70–180 inclusive);
IAE = trapezoid ∫|G − sp| dt; insulin = Σ U_i·dt over i = 0 … N−1 (U is constant over each step); time_at_Umax = Σ dt where
U_i ≥ U_max − 1e-9.

### 9.4 `margins()`

L(jω) = Gc(jω)·Gp(jω)·e^(−jωθ), with Gp the full 3rd-order linear model and Gc = Kc[1 + 1/(τI·s) + τD·s/(τD/N·s + 1)]
(the integral term is omitted when τI is null/∞). ωc = the highest-frequency |L| = 1 crossing in [1e-5, 10] rad/min.
Phase is built analytically from the factors (no numerical unwrapping); PM = 180° + ∠L(jωc).
GM = 1/|L| at the first −180° crossing (∞ if none). dtheta_max = PM[rad]/ωc; total_tolerable_delay = θ + dtheta_max `[C 11]`.
